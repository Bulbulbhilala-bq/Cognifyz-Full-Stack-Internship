# Task 8 - Middleware, Redis and Caching

## Project Overview

This project demonstrates Express.js middleware,
Redis integration and caching.

## Technologies Used

- Node.js
- Express.js
- Redis
- JavaScript

## Features

1. Custom Express Middleware
2. Redis Connection
3. Redis Caching
4. Cache Hit and Cache Miss
5. Cache Expiration (60 seconds)
6. Error Handling

## API Endpoint

GET /api/students

Returns a list of sample students.

## How to Run

1. Install dependencies:
   npm install

2. Start Redis server in Ubuntu:
   service redis-server start

3. Start the Node.js server:
   node server.js

4. Open:
   http://localhost:5003/api/students
